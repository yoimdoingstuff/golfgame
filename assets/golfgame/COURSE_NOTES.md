# Workshop course pack

Golfgame's original 18-hole starter course. Each hole is a compact raised minigolf diorama with green playing surfaces, pale retaining edges and playful obstacles. All geometry is procedurally authored for this project; no Open-Golf sample level files are shipped.

| 2 | Easy Does It | 3 | bumper |

The course files are emitted from the CMake data pack at build time. The single course-pack selector leads into an 18-hole sequential progression.
